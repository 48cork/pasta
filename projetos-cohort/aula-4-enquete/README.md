# 🐻 ResearchMate & AIOS-Sociologia (UFCG)

Bem-vindo ao ecossistema de **Humanidades Digitais** desenvolvido para a UACS/UFCG. Este repositório integra ferramentas pedagógicas para alunos e uma infraestrutura avançada de pesquisa sociológica.

## 📂 Organização do Ecossistema

### 🎓 1. ResearchMate (Frente Pedagógica)
Assistente web projetado para auxiliar alunos de graduação na compreensão de teorias clássicas. 
- **Objetivo:** Ensinar "como pensar sociologicamente".
- **Público:** Estudantes de Introdução à Sociologia.

### 📊 2. Sistema de Enquetes (Motor de Coleta)
Infraestrutura baseada em Linux/WSL para coleta de dados estruturados no campus.
- **Localização:** `projetos-cohort/aula-4-enquete/`
- **Ferramentas:** Scripts de automação e roteiros de entrevista (.md).

### 🔬 3. Projeto de Pesquisa (Núcleo de Inteligência)
Onde a "mágica" acontece. Utilizamos um **Squad de Agentes de IA** para realizar a análise multiparadigmática dos dados coletados.
- **Documentação:** [PROJETO_DE_PESQUISA.md](./PROJETO_DE_PESQUISA.md)
- **Evidências:** [evidencia_teste_01.md](./evidencia_teste_01.md)
