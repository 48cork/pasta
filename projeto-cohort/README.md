# Projeto Cohort

## Sociological Research Toolkit

Este projeto inclui um pequeno toolkit para pesquisa sociológica aplicada ao trabalho em plataformas:

- `codigo1/roteiro-sociologico.html`: roteiro estruturado de análise sociológica (com etapas de método, análise e conclusão).
- `codigo1/GUIA_ALUNO.md`: guia pedagógico para estudantes conduzirem entrevistas com trabalhadores de app usando Habitus e Alienação.

Para assegurar qualidade acadêmica, o conteúdo é revisado com workflow adversarial BMAD, validando critérios de aceitação, consistência conceitual e clareza estrutural.
